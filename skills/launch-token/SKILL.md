---
name: qhooks-launch-token
description: Use when the user asks to prepare a QHooks token launch or open its launch flow.
---

1. Read the current QHooks tool catalog and exact schema. Confirm the requested chain and reviewed launch details.
2. Use `prepare_launch` for the requested chain. Launch creation uses the QHooks site flow; Solana launch links use the existing Meteora DBC page and are signed there with the user's or agent's Solana wallet.
3. Show the returned review link and explain that a link or unsigned plan is not execution. Never claim a launch completed without confirmation from the actual flow.
